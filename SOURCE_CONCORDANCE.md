# Source Concordance

This concordance provides selected source-navigation entries from the research underlying *Connected Records: The Visual Atlas of the Epstein Files*.

The full Professional Review Edition contains a larger 72-entry candidate connection register spanning research Sections 377–382. This public GitHub version is intentionally smaller and is meant to demonstrate how documented connections are classified and traced back to source records.

## How to read the entries

Different kinds of records are not treated as interchangeable.

A proposal is not a completed transfer.  
A grant maximum is not a payment.  
An institutional donation does not establish project-level allocation.  
A correspondence contact does not establish direction, financing, or control.  
The same reported aggregate should not be counted twice.

Researchers should return to the original source, confirm the legal entities, dates, page location, amount, and transaction type, and preserve any limitation or unresolved issue before treating a connection as established.
